# Python Exercises

This folder contains small Python exercises created while practicing the fundamentals of the language.

Each file focuses on a specific concept and is kept intentionally simple.

## Exercises

| File | Topic |
| --- | --- |
| `user_intro_input.py` | User input and f-strings |
| `list_first_last_item.py` | List indexing |
| `list_length.py` | List length |
| `reverse_list.py` | Reversing lists |
| `count_list_items.py` | Counting items in a list |
| `remove_list_item.py` | Removing list items |
| `dictionary_lookup.py` | Dictionary access |
| `update_dictionary_value.py` | Updating dictionary values |
| `tuple_indexing.py` | Tuple indexing |
| `remove_duplicates_with_set.py` | Removing duplicates using sets |
| `set_union.py` | Set union |
| `age_condition.py` | Conditional statements |
| `membership_check.py` | Membership checks |
| `loop_through_names.py` | For loops |
| `add_value_in_loop.py` | Loop-based calculations |
| `even_odd_check.py` | Even/odd checks |
| `capitalize_names.py` | String capitalization |
| `dictionary_values_and_fstring.py` | Dictionaries and f-strings |
| `nested_data_access.py` | Accessing nested data |
| `nested_dictionary_list.py` | Nested dictionaries and lists |
| `user_profile_input.py` | Building dictionaries from user input |
| `simple_command_flow.py` | Basic command flow |

## Concepts Practiced

- Variables
- User input
- Strings
- Lists
- Tuples
- Dictionaries
- Sets
- Conditional statements
- Loops
- Nested data structures
